# Khaadi Pakistan UI Clone

A frontend UI clone of the Khaadi Pakistan website built using HTML & CSS only.
Focused on real-world layout practice and clean design thinking.


# Live Demo
https://bakhtawar-nizamani.github.io/khaadi-ui-clone/

# About This Project

This project is a frontend practice clone of the Khaadi Pakistan e-commerce website.

The goal was to recreate a real-world UI using only HTML and CSS, focusing on structure, spacing, and layout accuracy.

⚠️ This is NOT an official Khaadi website. It is made for learning purposes only.

# Features
 - Sticky navigation bar (like real e-commerce websites)
 - Hero section with banner image
 - Product grid layout (cards design)
 - Pricing & product labeling system
 - Bestsellers section layout
 - Structured UI sections (modern layout practice)
 - Multi-column footer design
 - Font Awesome icons integration
  
# Tech Stack
HTML5
CSS3
Flexbox
Font Awesome


# What I Learned

While building this project, I improved:

Structuring large real-world websites
Flexbox alignment and spacing control
Designing product cards like e-commerce platforms
Working with sticky navbar behavior
Creating reusable UI components
Improving visual hierarchy and layout balance

# Purpose

This project was built to improve frontend development skills by cloning a real-world e-commerce UI.

It helped me understand how professional websites are structured and designed.
